QUESTION 1

How did national parliamentary turnout change?

Turnout ranged from 56.3% in 1998 to 70.5% in 2002. It recovered to about 70% in 2018 and 2022 after declining through the 2010s.

Final national parliamentary turnout only. The supplied 2026 turnout file is a 19:00 snapshot, so it is intentionally excluded from this comparison.

QUESTION 2

What changed in 2026?

In the provided 2026 national party-list results, TISZA received 53.5% and FIDESZ–KDNP 38.9%. The opposition list in 2022 was a coalition, so it is not treated as directly comparable to a single 2026 party.

QUESTION 3

Where did support shift?

For the three lists present in both years, FIDESZ–KDNP’s share declined in every county between 2022 and 2026. The change ranged from −12.5 to −18.9 percentage points.

This is a within-party comparison using the full party-list vote denominator. It does not imply that votes transferred to any particular opponent.

QUESTION 4

How competitive were individual constituencies?

The project calculates the winner’s margin over the runner-up for all 106 individual constituencies in 2014, 2018, 2022, and 2026. This makes close races visible without confusing vote totals with vote-share margins.

METHOD

How this project is built

  1. Official ZIP, CSV, XLS, and XLSX election releases are read without altering the originals.
  2. Python cleaning scripts standardise the historical and 2026 tables, then validate totals against the published national lists.
  3. Jupyter notebooks document analysis; Tableau-ready CSV files support a companion dashboard.
  4. The repository excludes raw files and generated data where redistribution is not appropriate; every result can be reproduced from documented sources.
